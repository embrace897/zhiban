# 知办 · 校园事务智能体小程序

> 看懂通知，把事办好。

知办是一款面向大学生的微信小程序，以校园通知为入口，结合智能问答、知识检索与工具调用，帮助学生制定计划、准备材料和跟进任务。

## 核心功能

- **通知解析**：上传截图、文本或PDF，提取时间、地点、材料和办理要求，支持原文核对与修正。
- **智能问答**：围绕通知继续提问，检索适用资料并展示来源。
- **个性化规划**：结合个人日程、准备进度与已确认偏好，生成行动方案。
- **任务执行**：用户确认后创建任务、设置小程序内提醒、更新清单并辅助生成材料提纲。
- **变更跟踪**：对比补充通知，分析对现有任务与材料的影响，确认后调整安排。

核心流程：**上传通知 → 核对要求 → 提问与规划 → 确认执行 → 跟进与办结**。

## 首期场景

- **竞赛报名**：核对条件、整理材料、安排准备步骤。
- **课程材料提交**：梳理提交要求、检查清单、跟踪截止时间。

平台内“办结”表示用户确认准备或提交完成，不代表外部审批通过。小程序内提醒不等同于微信主动推送，订阅消息作为后续扩展。
