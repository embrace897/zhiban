状态：即时设计已搭建17页可编辑交互原型。下文的完整交互规则是设计目标，已验证范围与待细化项单独记录。

## 1 画布与组件

学生端与后台管理原型均采用390×844移动画布；后台按授权管理入口呈现，满足后台业务原型而不新增独立网页。若课程要求桌面管理画布，需再确认。安全区上下留白，8px间距体系，主色#174C64、背景#F5F8FA、正文#22343C。字号标题20、正文14、辅助12。按钮高44，卡片圆角12。重要错误用图标与文字，不能只变色。

公共组件：导航栏、底部导航、通知卡、时间节点、材料条目、来源引用、执行步骤卡、确认弹层、空态/加载/错误/无权状态。样例只使用虚构信息，不导入真实私人通知。

## 2 页面与点击行为

| 编号 | 页面/核心内容 | 交互与规则 |
|---|---|---|
| S01 | 首页：近期截止、缺失材料、待确认变更 | 上传→S02；事务卡→S04；消息→S10 |
| S02 | 上传：图片/PDF/文字、来源、发布时间 | 校验格式与大小；解析→加载→S03；失败可重试或手动填写 |
| S03 | 核对：原文展开、时间/地点/材料字段 | 未知年份标待补；定位依据；补充后保存→S04；返回保留草稿 |
| S04 | 事务：进度、时间、材料、文件、历史 | 咨询→S05；补充通知→S08；材料可勾选；办结弹层说明含义 |
| S05 | 助手：当前事务、输入框、引用、方案卡 | 询问可用时间；查看引用弹层；接受方案→S06 |
| S06 | 计划确认：逐项新增/修改、时间约束 | 编辑后确认版本更新；确认→S07；拒绝返回且不执行 |
| S07 | 执行：步骤状态、真实产物、失败说明 | 成功查看事务；部分成功只重试失败步骤；离开后可恢复 |
| S08 | 变更：原值/新值、依据、受影响任务 | 关联不明先选择；查看调整方案→S11；取消保留原安排 |
| S09 | 我的/记忆：长期偏好、来源和范围 | 保存偏好前确认；修改、停用、删除；区别聊天记录删除 |
| S10 | 内部提醒：未读、已读、取消 | 点击→对应事务；退出后到时入库，再进入可见，不模拟微信推送 |
| S11 | 确认调整：变更后的截止、检查提醒与签字待办 | 确认后进入S12，保留已完成事项 |
| S12 | 变更结果：已更新时间、待办和保留项 | 返回首页S01 |
| A01 | 后台概览：待审资料、失败任务、审计入口 | 维护角色可见，普通用户无权；卡片→A02/A04/A05 |
| A02 | 资料列表：草稿/发布/停用、机构和版本 | 上传补全元数据→A03；筛选；停用需确认 |
| A03 | 审核详情：来源、版本、有效期、片段 | 缺机构或来源阻止发布；发布成功回A02；退回填写理由 |
| A04 | 执行异常：任务ID、步骤、错误、结果 | 不展示密钥；可安全重试/待核实/取消未执行步骤 |
| A05 | 审计：操作者、动作、对象、时间 | 条件筛选，不默认展示用户私人正文；无权不能深入 |

## 6 演示范围与实现边界

上传、问答、生成材料及执行状态采用虚构示例；部分失败状态可展示，重试成功反馈尚未制作。输入编辑、真实文件下载、完整底部导航、加载/空态/版本冲突/无权状态仍需细化。左侧页面目录可覆盖全部17页，供课程评审浏览，不代表绕过成品权限。成品以微信小程序及服务端鉴权为准。
